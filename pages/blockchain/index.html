The SEED Blockchain Emulator (ChainSEED) is a scalable, high-fidelity blockchain emulation platform built on the SEED Internet Emulator. It allows users to construct and run blockchain networks using real client software across configurable Internet topologies. Supporting Ethereum, Monero, and Solana, the emulator provides Python APIs for customizing blockchain configurations, node settings, peer connections, and transaction workloads, with container-based deployment for experiments of different sizes.

Users can interact with emulated blockchains through familiar tools such as MetaMask, Remix, and Hardhat, deploy and test smart contracts, and observe blockchain activity through monitoring and visualization tools. ChainSEED enables researchers to investigate how network topology, routing behavior, client configurations, and transaction workloads affect blockchain performance and security. It provides a controllable and reproducible environment for studying consensus behavior, transaction propagation, scalability, routing attacks, and peer-to-peer network vulnerabilities.
