The Internet Emulator provides Python building blocks for autonomous systems, Internet exchanges, BGP routers, DNS infrastructure, and application services. Describe an experiment in code, generate its container configuration, and run a small Internet on your own machine.

Use it for hands-on networking courses, cybersecurity labs, and distributed systems research. Internet Map makes network topology and activity visible as experiments run.
